## Qué es
Reporte de la Bitácora de Eventos para RRHH/administradores y para supervisores: por **equipo** (una fila
por colaborador con conteos por tipo) y por **competencia** de un colaborador (resumen del periodo), con
rango de fechas y exportación a Excel.

## Colaboradores (ya existen; léelos, no los cambies)
- `Bitacora` (`src/app/Controllers/Bitacora`): `equipo(supervisor, desde?, hasta?)`, `resumen(empleado, periodoId)`,
  `listar(filtro)`, `periodoActivo()`, `filasExcel(eventos, nombre)`, `mensajeError(err)`.
- `Empleados` (`src/app/Controllers/Empleados`): `Gets(): Observable<ModelResponse>` → `data: IEmpleado[]` (todos),

- Utils `src/app/Helpers/bitacora-utils`: `rangoPeriodo`, `fechaCorta`, `textoResumen`, `claseTipo`, `normalizarTexto`, `hoyISO`.
- Modelos: `IBitacoraResumenEmpleado`, `IBitacoraResumenCompetencia`, `IBitacoraEvento` (`src/app/Models/Bitacora/IBitacora`), `IEmpleado`.

## Componente

```ts
@Component({ selector: 'app-reporte-bitacora', templateUrl, styleUrls, standalone: true, imports: [CommonModule, FormsModule] })
export class ReporteBitacoraComponent implements OnInit {
  constructor(private bitacora: Bitacora, private empl: Empleados, private datos: DatosServiceService, private excel: ExcelService) {}

  esAdmin: boolean;                   // rolId 1 del JSON 'rol'
  supervisores: IEmpleado[];          // admin: empleados con esjefatura === 1 (de Gets), ordenados por nombre; supervisor: solo él
  supervisorSel: number;              // secuencial elegido
  periodoId: number; rango: { desde: string; hasta: string };   // por defecto el rango del periodo activo (rangoPeriodo)
  filas: IBitacoraResumenEmpleado[]; cargando: boolean; error: string;
  detalle: { empleado: IBitacoraResumenEmpleado; competencias: IBitacoraResumenCompetencia[]; eventos: IBitacoraEvento[] } | null;

  ngOnInit(): void;                   // rol, usuario, periodo, rango por defecto, supervisores; si supervisor: consultar()
  consultar(): void;                  // bitacora.equipo(supervisorSel, rango.desde || null, rango.hasta || null) → filas
  get totales(): { logros; incumplimientos; iniciativas; conductas; total; colaboradores: number; conEventos: number };
  verDetalle(fila): void;             // forkJoin(resumen(sec, periodoId), listar({empleadoSecuencial: sec, desde, hasta})) → detalle
  cerrarDetalle(): void;
  exportarEquipo(): void;             // filas → Excel con claves: 'Colaborador','Cargo','Logros','Incumplimientos','Iniciativas','Conductas','Total','Último evento' (fechaCorta); nombre `bitacora_equipo_<supervisorSel>`
  exportarDetalle(): void;            // bitacora.filasExcel(detalle.eventos, detalle.empleado.nombre) → `bitacora_<sec>`
  textoResumen(f): string; fechaCorta(f): string; claseTipo(t): string;
}
```

## Plantilla
1. Título "Reporte de Bitácora de Eventos". Fila de filtros: `select` supervisor (deshabilitado si no es admin),
   `input type=date` desde/hasta, botón "Consultar" (`btn btn-primary`), botón "Exportar Excel" (`btn btn-outline-success`, `[disabled]="!filas.length"`).
2. Tarjetas de totales (`.tarjeta-total`): Colaboradores, Con eventos, Logros, Incumplimientos, Iniciativas, Conductas, Total.
3. Tabla `table table-sm table-hover`: Colaborador, Cargo, Logros, Incumplimientos, Iniciativas, Conductas, Total,
   Último evento, y botón "Ver" por fila (`(click)="verDetalle(f)"`). Filas con total 0 en gris (`.sin-eventos`).
   `cargando` → spinner; `error` → `alert alert-danger`; sin filas tras consultar → "Sin colaboradores o sin eventos en el rango.".
4. Panel de detalle (`.detalle` debajo de la tabla, no modal) cuando `detalle`: cabecera con nombre y cargo,
   botón "Cerrar" y "Exportar Excel"; lista de competencias con `textoResumen` (`.competencia-fila`, en gris si 'Sin eventos');
   y tabla de eventos del rango (fecha corta, tipo con badge `claseTipo`, impacto, descripción, competencias por nombre, registrado por).

## Criterios de aceptación
1. Con `rol` = `{rolId: 1}`, `supervisores` = solo jefaturas (`esjefatura === 1`) ordenadas por nombre; con `{rolId: 2}`, `supervisores` = [él] y `consultar()` se llama solo al iniciar.
2. `consultar()` llama a `equipo(55, '2026-06-01', '2026-12-31')` con el rango del periodo activo por defecto; con inputs vacíos manda `null`.
3. `totales` suma las filas y cuenta `conEventos` = filas con total > 0.
4. `verDetalle` llama a `resumen` y `listar` y llena `detalle`; `cerrarDetalle` lo anula.
5. `exportarEquipo` produce filas con las 8 claves exactas y el nombre `bitacora_equipo_55`.
6. Error de `equipo` → `error` con `mensajeError` y `cargando=false`.
