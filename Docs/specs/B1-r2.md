## Errores y corrección exacta

1. **Línea ~48** (`GetBitacoraEventos`, GET lista): `return await CompletarAEvt(eventos);` — CS0029: no se
   puede convertir `IEnumerable<BitacoraEventoDto>` a `ActionResult<IEnumerable<…>>`.
   **Corrección:** envuelve en `Ok(...)`: `return Ok(await CompletarAEvt(eventos));` (o `.ToList()` y `Ok`).
   Además unifica los nombres: en el archivo aparecen `CompletarAEvt`, `CompletarA` y `Completar`. Debe
   quedar UNA sola función auxiliar que reciba `List<BitacoraEvento>` y devuelva `Task<List<BitacoraEventoDto>>`
   (rellena Nombre/Grupo de las competencias y RegistradoPorNombre), llámala `CompletarDto`, y úsala en
   todos los endpoints que devuelven eventos.

2. **Línea ~64** (`GetBitacoraEvento`): `BitacoraEventoDto.De(evento, await NombrePorEventoN(new[] { evento }))`
   — CS1503: `NombrePorEventoN` recibe un arreglo cuando espera un `BitacoraEvento`.
   **Corrección:** `var dtos = await CompletarDto(new List<BitacoraEvento> { evento }); return dtos[0];`
   y elimina `NombrePorEventoN` si queda sin uso.

3. **Línea ~93** (`PostBitacoraEvento`): `CompletarA(eventos: …)` — CS0103: no existe.
   **Corrección:** `var dtos = await CompletarDto(new List<BitacoraEvento> { guardado });`.

4. **Línea ~189** (`Resumen`): `eventos.Select(e => BitacoraEventoDto.De(e, await NombreAutorPorSecuencial(...)))`
   — CS4034: `await` dentro de una lambda no `async`.
   **Corrección:** no uses `await` dentro de `Select`. Haz `var dtos = await CompletarDto(eventos);` (una
   sola consulta de nombres de autores: `var autores = eventos.Select(e => e.RegistradoPorSecuencial).Distinct()`,
   luego `_context.Empleados.Where(x => autores.Contains(x.SECUENCIAL)).ToListAsync()`, agrupado por
   `SECUENCIAL` tomando el primero) y luego `dtos.Where(...)` para armar `eventos` de cada fila del resumen.

5. **Líneas ~247 y ~270** (`Equipo`): `s.primer.NOMBREUNIDO` — CS1061: la proyección se llamó `primero`, no `primer`.
   **Corrección:** usa el mismo nombre en la proyección y en el uso: `new { Key = g.Key, primero = g.First() }`
   y `s.primero.NOMBREUNIDO`, `s.primero.CARGO`.

6. **Línea ~261** (`Equipo`): `ultimoEvento = (DateTime?)evs.Count > 0 ? evs.Max(x => x.FechaEvento) : null`
   — CS0030: el cast se aplica a `evs.Count`. **Corrección:**
   `ultimoEvento = evs.Count > 0 ? (DateTime?)evs.Max(x => x.FechaEvento) : null`.

7. **`Equipo`, bloque duplicado:** hay dos construcciones de filas (una con eventos y otra "filasVacias").
   Déjala en UNA sola: calcula `eventos` (lista vacía si no hay subordinados o el rango no trae nada) y
   proyecta siempre las filas por subordinado con los conteos (que darán 0). Elimina la segunda copia.
