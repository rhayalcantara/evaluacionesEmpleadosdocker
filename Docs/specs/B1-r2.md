## Crítica 1 (única): el nombre del autor se consulta una vez por evento

- `CompletarAEvt` (aprox. líneas 333-337) hace `await NombreAutorPorSecuencial(e.RegistradoPorSecuencial)`
  **dentro del `foreach`** de eventos, y `GetResumen` (aprox. línea 191) repite el mismo patrón.
  `NombreAutorPorSecuencial` (aprox. 320-326) ejecuta una consulta a la vista `Empleados` por llamada.
- Medido contra el API de prueba: 0.267 s por evento, lineal. 15 eventos = 3.99 s; el `resumen` del
  periodo 8 con 13 eventos = 3.79 s. El frontend tiene timeout de 10 s.

### Corrección exacta
1. Añade un helper privado que resuelva **todos** los autores de una lista de eventos en **una sola consulta**,
   agrupando por `SECUENCIAL` porque la vista `Empleados` tiene filas duplicadas (mismo patrón que ya usas
   en `GetEquipo`, aprox. líneas 233-239):
   ```csharp
   private async Task<Dictionary<int, string>> NombresAutores(IEnumerable<BitacoraEvento> eventos)
   {
       var secs = eventos.Select(e => e.RegistradoPorSecuencial).Distinct().ToList();
       if (secs.Count == 0) return new Dictionary<int, string>();
       var filas = await _context.Empleados
           .Where(x => secs.Contains(x.SECUENCIAL))
           .Select(x => new { x.SECUENCIAL, x.NOMBREUNIDO })
           .ToListAsync();
       return filas.GroupBy(x => x.SECUENCIAL)
                   .ToDictionary(g => g.Key, g => g.First().NOMBREUNIDO ?? "");
   }
   ```
2. En `CompletarAEvt` (o como se llame el helper que convierte `List<BitacoraEvento>` en
   `List<BitacoraEventoDto>`): llama a `NombresAutores(eventos)` **una vez antes del bucle** y dentro del
   bucle usa `autores.TryGetValue(e.RegistradoPorSecuencial, out var nombre) ? nombre : null`.
3. En `GetResumen`: elimina la llamada por evento a `NombreAutorPorSecuencial` y usa el mismo helper
   (`CompletarAEvt`/`NombresAutores`) una sola vez para todos los eventos del periodo.
4. `NombreAutorPorSecuencial` puede quedarse **solo** si sigue usándose en `GET /{id}` (un evento); si ya no
   se usa en ningún sitio, elimínala.
5. Opcional (no obligatorio): en `GetResumen`, aprox. líneas 195-197, se vuelve a consultar `Objetivo` para
   nombres que `Completar` ya dejó en `c.Nombre`; puedes reutilizar `c.Nombre` y ahorrar esa consulta.
