## Endpoints reales del API (respuestas crudas, NO envueltas en ModelResponse)
| Método | URL | Devuelve |
|---|---|---|
| GET | `${URL}/api/BitacoraEventos?empleadoid=&desde=&hasta=&tipo=&objetivoid=` | `IBitacoraEvento[]` |
| GET | `${URL}/api/BitacoraEventos/{id}` | `IBitacoraEvento` (404 si no existe) |
| POST | `${URL}/api/BitacoraEventos` | 201 `IBitacoraEvento` |
| PUT | `${URL}/api/BitacoraEventos/{id}` | 204 sin cuerpo |
| DELETE | `${URL}/api/BitacoraEventos/{id}?secuencial=` | 204 sin cuerpo |
| GET | `${URL}/api/BitacoraEventos/resumen?empleadoid=&periodoid=` | `IBitacoraResumenCompetencia[]` |
| GET | `${URL}/api/BitacoraEventos/equipo?supervisor=&desde=&hasta=` | `IBitacoraResumenEmpleado[]` |
| GET | `${URL}/api/Objetivoes` | **`ModelResponse<IObjetivo[]>`** (este sí viene envuelto: usar `getdatos`) |
| GET | `${URL}/api/Periods/activo` | `{ id, descripcion, fechaInicio, fechaFin, tipo }` (crudo: `getbyid`) |

Los errores 400 del API traen `{ mensaje: string }` en el cuerpo.

## Contrato de la clase

```ts
@Injectable({ providedIn: 'root' })
export class Bitacora {
  constructor(private datos: DatosServiceService, private logger: LoggerService) {}

  readonly rutaapi: string;   // `${this.datos.URL}/api/BitacoraEventos`

  /** GET lista. Solo añade a la query los filtros con valor (no manda `tipo=null` ni `desde=`). */
  listar(filtro: IBitacoraFiltro): Observable<IBitacoraEvento[]>;
  /** GET por id. */
  obtener(id: number): Observable<IBitacoraEvento>;
  /**
   * Valida con `validarEvento`; si no es válido devuelve `throwError(() => new Error(errores.join(' ')))`
   * SIN llamar al API. Si es válido: POST cuando `id` es 0/undefined, PUT cuando `id > 0`.
   * En PUT, como el API responde 204, emite el mismo evento enviado (con `fechaModificacion` sin tocar).
   */
  guardar(evento: IBitacoraEvento): Observable<IBitacoraEvento>;
  /** DELETE lógico. Emite `true` al completar. */
  eliminar(id: number, secuencial: number): Observable<boolean>;
  /** GET resumen por competencia del periodo. */
  resumen(empleadoSecuencial: number, periodoId: number): Observable<IBitacoraResumenCompetencia[]>;
  /** GET resumen de equipo. `desde`/`hasta` opcionales; solo se añaden si tienen valor. */
  equipo(supervisorSecuencial: number, desde?: string | null, hasta?: string | null): Observable<IBitacoraResumenEmpleado[]>;

  /**
   * Catálogo de competencias del periodo: GET /api/Objetivoes una sola vez para toda la vida del servicio
   * (shareReplay(1)), luego filtra en memoria por `periodoId` y mapea a ICompetenciaCatalogo
   * { objetivoId: id, nombre, grupoId: grupoCompetenciaId, grupo: grupoCompetencia?.nombre ?? '' },
   * ordenado por grupoId y luego id. Periodo sin competencias → [].
   */
  catalogoCompetencias(periodoId: number): Observable<ICompetenciaCatalogo[]>;
  /** Olvida la caché del catálogo. */
  limpiarCacheCatalogo(): void;

  /** GET /api/Periods/activo. */
  periodoActivo(): Observable<{ id: number; descripcion: string; fechaInicio: string; fechaFin: string; tipo: string }>;

  /** Atajo: eventoNuevo de bitacora-utils. */
  nuevo(empleadoSecuencial: number, registradoPorSecuencial: number): IBitacoraEvento;
  /** Atajo: validarEvento de bitacora-utils. */
  validar(evento: IBitacoraEvento): IValidacionEvento;
  /** Atajo: filasExcel de bitacora-utils. */
  filasExcel(eventos: IBitacoraEvento[], nombreEmpleado: string): Record<string, string | number>[];

  /** Texto legible de un HttpErrorResponse: `error.error.mensaje` si existe; si no `error.message`; si no 'Error desconocido'. */
  mensajeError(error: unknown): string;
}
```

## Reglas
- Construye las URLs con `URLSearchParams`/concatenación segura (`encodeURIComponent` en strings).
- `listar` con `empleadoSecuencial <= 0` → `throwError(() => new Error('Falta el colaborador.'))` sin llamar al API.
- Cada método HTTP registra `this.logger.debug('<acción>', {…parámetros})`; los errores NO se tragan
  (no `catchError` que devuelva vacío): el componente decide qué mostrar con `mensajeError`.
- `catalogoCompetencias`: la petición cacheada es `this.datos.getdatos<IObjetivo[]>(URL + '/api/Objetivoes')`
  → usa `resp.data ?? []`. Filtra `o.periodoId === periodoId`.
- `guardar` normaliza antes de enviar: `descripcion.trim()`, `fechaEvento` en `'YYYY-MM-DD'` (primeros 10
  caracteres si viene con hora), competencias con `id: 0` cuando no lo tengan y `bitacoraEventoId: evento.id ?? 0`.
- Sin `any` salvo en `mensajeError`. Sin `console.*`. Comentarios breves en español.

## Criterios de aceptación (batería con HttpClientTestingModule)
1. `listar({empleadoSecuencial: 525, tipo: 'Logro', desde: null})` hace GET a
   `…/api/BitacoraEventos?empleadoid=525&tipo=Logro` (sin `desde`) y emite el array.
2. `listar({empleadoSecuencial: 0})` emite error sin petición HTTP.
3. `guardar` de un evento inválido emite error con los mensajes de `validarEvento` unidos por espacio y NO hace petición.
4. `guardar` con `id: 0` hace POST y emite la respuesta; con `id: 7` hace PUT a `…/7` y emite el evento enviado.
5. `eliminar(7, 55)` hace DELETE a `…/7?secuencial=55` y emite `true`.
6. `catalogoCompetencias(8)` dos veces seguidas → una sola petición a `/api/Objetivoes`; devuelve solo las de periodoId 8 mapeadas y ordenadas; `limpiarCacheCatalogo()` provoca una nueva petición.
7. `resumen(525, 8)` → GET `…/resumen?empleadoid=525&periodoid=8`; `equipo(55)` → GET `…/equipo?supervisor=55` (sin desde/hasta).
8. `mensajeError({error:{mensaje:'X'}})` → `'X'`; `mensajeError(new Error('Y'))` → `'Y'`; `mensajeError(null)` → `'Error desconocido'`.
