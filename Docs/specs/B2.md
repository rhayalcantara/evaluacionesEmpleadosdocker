Contexto: la Bitácora de Eventos de Desempeño registra hechos observables de un colaborador (fecha
del hecho, tipo `Logro|Incumplimiento|Iniciativa|Conducta`, impacto `Alto|Medio|Bajo`, descripción,
competencias evidenciadas). El API valida lo mismo; estas funciones dan mensajes inmediatos en pantalla.

## Funciones a exportar (firmas exactas)

```ts
import {
  IBitacoraEvento, IBitacoraEventoCompetencia, IBitacoraResumenCompetencia, ICompetenciaCatalogo,
  IValidacionEvento, TipoEvento, ImpactoEvento, TIPOS_EVENTO, IMPACTOS_EVENTO, DESCRIPCION_MIN, DESCRIPCION_MAX
} from '../Models/Bitacora/IBitacora';

/** 'YYYY-MM-DD' de la fecha local (sin UTC). Acepta Date o string ISO/'YYYY-MM-DD'; inválido → ''. */
export function fechaISO(fecha: Date | string | null | undefined): string;

/** Hoy en 'YYYY-MM-DD' local. Recibe opcionalmente el "ahora" para pruebas. */
export function hoyISO(ahora?: Date): string;

/** Minúsculas, sin acentos/diacríticos, espacios colapsados, trim. null/undefined → ''. */
export function normalizarTexto(texto: string | null | undefined): string;

/** Evento vacío listo para el formulario (id 0, fecha = hoy, tipo 'Logro', impacto 'Medio', sin competencias). */
export function eventoNuevo(empleadoSecuencial: number, registradoPorSecuencial: number, ahora?: Date): IBitacoraEvento;

/**
 * Valida un evento antes de enviarlo. `errores` en este orden fijo (solo los que fallen):
 *  1. 'Seleccione el colaborador.'                         (empleadoSecuencial <= 0 o no numérico)
 *  2. 'La fecha del evento es obligatoria.'                (fechaEvento vacía o inválida)
 *  3. 'La fecha del evento no puede ser futura.'           (fechaEvento > hoy; hoy inclusive es válido)
 *  4. 'Seleccione el tipo de evento.'                      (tipo no está en TIPOS_EVENTO, comparación exacta)
 *  5. 'Seleccione el impacto.'                             (impacto no está en IMPACTOS_EVENTO)
 *  6. `La descripción debe tener al menos ${DESCRIPCION_MIN} caracteres.` (descripción trim < 30)
 *  7. `La descripción no puede superar ${DESCRIPCION_MAX} caracteres.`     (descripción trim > 2000)
 *  8. 'Seleccione al menos una competencia.'               (sin competencias)
 *  9. 'Hay competencias repetidas.'                        (objetivoId repetido)
 * valido = errores.length === 0. No muta el evento.

export function validarEvento(evento: IBitacoraEvento, ahora?: Date): IValidacionEvento;

/** Etiqueta del tipo ('Logro'…); desconocido → el texto tal cual o '' si null. */
export function etiquetaTipo(tipo: string | null | undefined): string;

export function claseTipo(tipo: string | null | undefined): string;
/** Clase CSS del impacto: 'impacto-alto' | 'impacto-medio' | 'impacto-bajo'; desconocido → 'impacto-otro'. */
export function claseImpacto(impacto: string | null | undefined): string;

export function alternarCompetencia(lista: IBitacoraEventoCompetencia[], objetivoId: number): IBitacoraEventoCompetencia[];
/** true si la competencia está en la lista. */
export function tieneCompetencia(lista: IBitacoraEventoCompetencia[] | null | undefined, objetivoId: number): boolean;

export function nombresCompetencias(evento: IBitacoraEvento): string;

/**

/** Rango de fechas de un periodo como {desde, hasta} en 'YYYY-MM-DD'; entradas inválidas → ''. */
```

## Reglas de implementación
- `fechaISO`: para `Date`, usa año/mes/día **locales** (`getFullYear/getMonth/getDate`); para string, si
  empieza por `YYYY-MM-DD` devuelve esos 10 caracteres sin convertir a Date (evita el corrimiento UTC);
  cualquier otra cosa → `new Date(valor)` y si es inválida → `''`.
- `normalizarTexto`: `normalize('NFD')` + quitar `[̀-ͯ]`, `toLowerCase`, `replace(/\s+/g,' ')`, `trim`.
- `validarEvento`: la comparación de fechas se hace con strings `'YYYY-MM-DD'` (`fechaISO(evento.fechaEvento) > hoyISO(ahora)`).
- Nada de `any`; tipa con las interfaces del modelo. Sin `console.*`. Comentarios breves en español.

## Criterios de aceptación (batería del orquestador)
1. `fechaISO(new Date(2026, 8, 5))` → `'2026-09-05'`; `fechaISO('2026-09-05T00:00:00')` → `'2026-09-05'`; `fechaISO('x')` → `''`.
2. `validarEvento` de un evento válido → `{valido:true, errores:[]}`; de uno vacío → los 9 mensajes en orden (empleado 0, fecha '', tipo '', impacto '', descripción '', sin competencias → solo aplican 1,2,4,5,6,8: exactamente esos, en ese orden).
3. Fecha de mañana → solo el error 3; fecha de hoy → sin error de fecha.
4. `alternarCompetencia([], 5)` → 1 elemento `{id:0,bitacoraEventoId:0,objetivoId:5}`; volver a alternar → `[]`; el array original no cambia.
5. `contarPorTipo` con 2 logros, 1 conducta y 1 tipo raro → `{logros:2, incumplimientos:0, iniciativas:0, conductas:1, total:4}`.
6. `textoResumen({logros:1,incumplimientos:2,iniciativas:0,conductas:1,total:4})` → `'1 logro · 2 incumplimientos · 1 conducta'`; total 0 → `'Sin eventos'`.
7. `filtrarEventos` con `desde:'2026-09-01', hasta:'2026-09-30'` incluye el 2026-09-01 y el 2026-09-30 y excluye el 2026-08-31; excluye siempre `activo:false`.
8. `filasExcel` produce las 8 claves exactas en orden.
