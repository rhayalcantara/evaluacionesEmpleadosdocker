## Qué es (borrador de RRHH, láminas 1 y 3)
Página **Bitácora de Eventos de Desempeño** para el supervisor: elige un colaborador de su equipo,
ve su cabecera (nombre, cargo, departamento), la lista de eventos registrados con filtros, y puede
**registrar**, **editar** y **eliminar** eventos (solo los suyos), y **exportar a Excel**.
Principio que debe leerse en pantalla: *"Registra HECHOS observables (situación · acción · resultado),
no interpretaciones. La fecha es la del hecho, no la del registro."*

## Componente

```ts
@Component({ selector: 'app-bitacora', templateUrl, styleUrls, standalone: true,
  imports: [CommonModule, FormsModule] })
export class BitacoraComponent implements OnInit {
  constructor(private bitacora: Bitacora, private empl: Empleados, private datos: DatosServiceService, private excel: ExcelService) {}

  // estado
  supervisor: IEmpleado | null;           // el usuario logueado (GetByUsuario)
  equipo: IEmpleado[];                    // subordinados
  seleccionado: IEmpleado | null;
  periodoId: number;                      // de localStorage; si no hay, periodoActivo().id
  catalogo: ICompetenciaCatalogo[]; grupos: {grupoId; grupo; competencias}[];
  eventos: IBitacoraEvento[];             // tal cual vienen del API (ya ordenados)
  filtro: { desde: string; hasta: string; tipo: string; objetivoId: number | null };  // valores '' / null = sin filtro
  cargando: boolean; error: string;       // error de carga de lista
  // formulario (diálogo propio con Bootstrap, sin MatDialog)
  editando: IBitacoraEvento | null;       // null = cerrado
  erroresForm: string[]; guardando: boolean;
  readonly tipos = TIPOS_EVENTO; readonly impactos = IMPACTOS_EVENTO; readonly descMin = DESCRIPCION_MIN; readonly descMax = DESCRIPCION_MAX;
  readonly hoy = hoyISO();

  ngOnInit(): void;                      // lee usuario/periodo, carga supervisor y equipo, catálogo
  seleccionar(emp: IEmpleado): void;     // fija seleccionado, limpia filtro y recarga eventos
  cargarEventos(): void;                 // bitacora.listar({empleadoSecuencial, ...filtro con valor}) → eventos; error → this.error = mensajeError
  limpiarFiltros(): void;
  get eventosVisibles(): IBitacoraEvento[];  // filtrarEventos + ordenarEventos sobre `eventos` (defensa en cliente)
  get conteo(): { logros; incumplimientos; iniciativas; conductas; total };  // contarPorTipo(eventosVisibles)
  nuevoEvento(): void;                   // editando = bitacora.nuevo(seleccionado.secuencial, supervisor.secuencial)
  editar(ev: IBitacoraEvento): void;     // editando = copia profunda (JSON) de ev
  esPropio(ev: IBitacoraEvento): boolean;// ev.registradoPorSecuencial === supervisor.secuencial
  alternar(objetivoId: number): void;    // editando.competencias = alternarCompetencia(...)
  tiene(objetivoId: number): boolean;
  get caracteres(): number;              // editando.descripcion.trim().length
  guardar(): void;                       // valida (erroresForm); si ok bitacora.guardar → showMessage success, cerrar, cargarEventos; error → showMessage error con mensajeError
  cancelar(): void;                      // editando = null; erroresForm = []
  eliminar(ev: IBitacoraEvento): void;   // Swal.fire confirm (título 'Eliminar evento', texto con la fecha corta y el tipo, botones 'Eliminar'/'Cancelar'); si confirma → bitacora.eliminar → showMessage success + cargarEventos
  exportar(): void;                      // excel.exportAsExcelFile(bitacora.filasExcel(eventosVisibles, seleccionado.nombreunido), `bitacora_${seleccionado.secuencial}`)
  nombresCompetencias(ev): string; fechaCorta(f): string; claseTipo(t): string; claseImpacto(i): string;  // delegan en utils
}
```
`Swal` se importa como `import Swal from 'sweetalert2'` (ya está en el proyecto; ver `card-empleado.component.ts`).

## Plantilla (estructura obligatoria; usa clases Bootstrap 5 y las CSS propias indicadas)
1. `<div class="bitacora-page container-fluid">` con `<h2>` "Bitácora de Eventos de Desempeño" y subtítulo
   "Registro de comportamientos observables · Insumo para la evaluación formal".
2. Fila con dos columnas:
   - Izquierda `col-lg-3` **equipo**: `<input class="form-control" placeholder="Buscar colaborador" [(ngModel)]="busqueda">`
     y lista `<button class="list-group-item list-group-item-action equipo-item" [class.active]="seleccionado?.secuencial===e.secuencial" (click)="seleccionar(e)">`
     con `nombreunido` y `<small>{{cargo}}</small>`; filtra por `busqueda` (sin acentos, minúsculas). Si `equipo` está
     vacío tras cargar: texto "No tiene colaboradores a cargo en este periodo.".
   - Derecha `col-lg-9`: si no hay seleccionado, `<div class="alerta-guia">` con el principio de la bitácora.
     Si hay seleccionado:
     a. **Cabecera** `.cabecera-colaborador`: nombre (`h4`), cargo, departamento, identificación, y el conteo:
        `<span class="badge evento-logro">{{conteo.logros}} logros</span>` (uno por tipo, mismas clases `claseTipo`).
     b. **Barra de acciones**: botón `btn btn-primary` "Registrar evento" `(click)="nuevoEvento()"`, botón
        `btn btn-outline-success` "Exportar Excel" `(click)="exportar()"` `[disabled]="!eventosVisibles.length"`.
     c. **Filtros** en una fila: `input type=date` desde, `input type=date` hasta, `select` tipo (opción "Todos" = ''),
        `select` competencia (opción "Todas" = null, `<optgroup>` por grupo), botón "Limpiar". Cada cambio llama `cargarEventos()`.
     d. **Lista**: `cargando` → spinner Bootstrap; `error` → `alert alert-danger` con el texto; sin eventos →
        `alert alert-light` "Sin eventos registrados con estos filtros."; con eventos → una `.evento-card` por evento:
        fila superior con `<span class="badge" [ngClass]="claseTipo(ev.tipo)">{{ev.tipo}}</span>`,
        `<span class="badge" [ngClass]="claseImpacto(ev.impacto)">Impacto {{ev.impacto}}</span>`, fecha corta del hecho,
        y a la derecha botones "Editar"/"Eliminar" (`btn btn-sm btn-outline-secondary` / `btn-outline-danger`)
        **solo si `esPropio(ev)`**; cuerpo: descripción; pie `<small>`: competencias (`nombresCompetencias`) y
        "Registrado por {{ev.registradoPorNombre}} el {{fechaCorta(ev.fechaRegistro)}}".
3. **Diálogo del formulario** (cuando `editando`): `<div class="modal d-block" tabindex="-1"><div class="modal-dialog modal-lg">…`
   con fondo `.modal-backdrop show`. Título "Registrar evento" o "Editar evento" según `editando.id`.
   Campos, en este orden, todos con `<label>` y `name`:
   - Fecha del evento: `input type=date [(ngModel)]="editando.fechaEvento" [max]="hoy"` + ayuda "Fecha en que ocurrió el hecho, no cuando lo anotas."
   - Tipo: grupo de botones `btn-group` con un `button type=button` por `tipos` (`class.active` cuando coincide).
   - Impacto: `select` con `impactos`.
   - Descripción: `textarea rows=4 [(ngModel)]="editando.descripcion" [maxlength]="descMax"` con placeholder
     "¿Qué ocurrió? ¿En qué contexto? ¿Cuál fue el resultado o impacto inmediato?" y contador
     `<small [class.text-danger]="caracteres < descMin">{{caracteres}}/{{descMax}} (mínimo {{descMin}})</small>`.
   - Competencias que impacta: por cada grupo un `<fieldset class="grupo-competencias"><legend>{{grupo}}</legend>` y
     un `form-check` por competencia (`input type=checkbox [checked]="tiene(c.objetivoId)" (change)="alternar(c.objetivoId)"`).
   - `erroresForm` → `<ul class="alert alert-warning">` con un `<li>` por mensaje.
   - Pie: "Cancelar" (`btn btn-secondary`) y "Guardar" (`btn btn-primary` `[disabled]="guardando"`).
4. Sin `*ngIf` anidados de más de 3 niveles; sin lógica compleja en la plantilla (usa los getters).

## Reglas
- Nada de `any` salvo el JSON de `localStorage`. Sin `console.*`. Comentarios breves en español.
- No uses `setTimeout` salvo el sondeo de `getsubordinados` (copiado del componente de referencia).
- Los mensajes al usuario van por `datos.showMessage`; nunca `alert()`.
- El componente no calcula nada que ya esté en `bitacora-utils`.

## Criterios de aceptación (batería del orquestador con `TestBed` y `Bitacora` simulado)
1. Con `localStorage` sin usuario, `ngOnInit` no llama a `GetByUsuario` ni rompe.
2. `seleccionar(emp)` limpia el filtro y llama a `bitacora.listar` con `{empleadoSecuencial: emp.secuencial}` (sin claves vacías).
3. `eventosVisibles` excluye `activo:false` y respeta el filtro de tipo en cliente.
4. `nuevoEvento()` abre el diálogo con `editando.id === 0`, `empleadoSecuencial` del seleccionado y `registradoPorSecuencial` del supervisor.
5. `guardar()` con descripción corta llena `erroresForm` y NO llama a `bitacora.guardar`; con evento válido llama, muestra éxito, cierra y recarga.
6. `esPropio` es falso para un evento de otro autor y la plantilla no muestra sus botones Editar/Eliminar.
7. `alternar(59)` dos veces deja `editando.competencias` vacío.
8. `exportar()` llama a `exportAsExcelFile` con las filas de `filasExcel` y nombre `bitacora_<secuencial>`.
9. Un error del API en `cargarEventos` deja `error` con el texto de `mensajeError` y `cargando=false`.
